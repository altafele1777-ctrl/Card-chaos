# فوضى الوحوش — بناء IPA من الآيفون (نسخة الأجزاء الثلاثة)

ملف اللعبة كبير (~٥٨ ميجا) ويتجاوز حد رفع متصفح GitHub (٢٥ ميجا للملف).
لذلك قُسِّم إلى ٣ أجزاء صغيرة داخل مجلد `www/parts/`، وملف البناء سيدمجها
تلقائياً قبل بناء التطبيق. أنت فقط ترفع الأجزاء — الباقي تلقائي.

النتيجة: ملف IPA **غير موقّع** للتثبيت على جهاز **مهكّر** (TrollStore / AppSync).

---

## محتويات الحزمة
```
chaos-app/
├── www/
│   └── parts/
│       ├── index.part.aa   (جزء ١ — ٢٠ ميجا)
│       ├── index.part.ab   (جزء ٢ — ٢٠ ميجا)
│       └── index.part.ac   (جزء ٣ — ١٧ ميجا)
├── .github/workflows/build.yml   (يدمج الأجزاء + يبني IPA)
├── capacitor.config.json
├── package.json
├── .gitignore
└── README.md
```

> ملاحظة: لا يوجد ملف `index.html` كامل في الحزمة — هذا مقصود.
> الملف يتكوّن تلقائياً من دمج الأجزاء أثناء البناء على GitHub.

---

## الخطوات من الآيفون

### ١. فُكّ ضغط الحزمة
حمّل ملف ZIP، ومن تطبيق **Files** اضغط عليه ليُفَك. سيظهر مجلد `chaos-app`.

### ٢. أنشئ حساب ومستودع GitHub
- من المتصفح: ادخل github.com وسجّل (مجاني).
- اضغط **New** لإنشاء مستودع.
- اختر **Public** (مهم).
- لا تضف README ولا أي ملف — اتركه فاضي.
- اضغط **Create repository**.

### ٣. ارفع الملفات
كل الملفات صغيرة (أكبرها ٢٠ ميجا)، فالرفع من المتصفح يقبلها.

**المشكلة الوحيدة:** متصفح الآيفون لا يرفع مجلدات بسهولة، وملف الـ workflow
داخل مجلد مخفي (`.github`). لذلك أسهل طريقة من الآيفون هي تطبيق **Working Copy**:

#### الطريقة (Working Copy — مجاني):
1. حمّل **Working Copy** من App Store.
2. افتحه ← اضغط ➕ ← **Clone repository**.
3. سجّل دخول GitHub والصق رابط مستودعك ← Clone.
4. اضغط على اسم المستودع ← زر المشاركة/الاستيراد ← **Import files** أو اسحب
   محتويات مجلد `chaos-app` (بما فيها مجلد `.github` و `www/parts`).
   - تأكد أن البنية تبقى نفسها: `www/parts/index.part.aa` وهكذا.
5. ارجع للمستودع في Working Copy ← اضغط **Commit** ← اكتب رسالة ← **Push**.

> Working Copy يحافظ على المجلدات المخفية والبنية كاملة، وهذا أهم شيء هنا.

### ٤. تابع البناء
- من المتصفح: افتح المستودع ← تبويب **Actions**.
- ستجد **Build Unsigned IPA** تشتغل تلقائياً (٥–١٥ دقيقة).
- أول خطوة فيها تدمج الأجزاء وتطبع حجم الملف — تقدر تتابع السجل.

### ٥. نزّل الـ IPA
- بعد علامة ✓ الخضراء، افتح العملية ← انزل لـ **Artifacts**.
- نزّل **chaos-unsigned-ipa**.

### ٦. ثبّت على جهازك المهكّر
- فك الضغط لتحصل على `app-unsigned.ipa`.
- ثبّته عبر **TrollStore** أو **Filza + AppSync Unified**.

---

## مهم
- ترتيب الأجزاء يعتمد على أسمائها (aa, ab, ac) — لا تغيّر الأسماء.
- لو فشل البناء: افتح السجل في Actions، وانسخ لي رسالة الخطأ لأصلحها.
- اسم التطبيق: **فوضى الوحوش** (يتغيّر من `capacitor.config.json`).
