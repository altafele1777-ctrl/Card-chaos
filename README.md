# لوحة طلبات أسواق الفكهاني — بناء APK

هاي الحزمة تبني تطبيق APK من لوحة الطلبات تلقائياً عبر GitHub.

## كيف تستعمله

1. ارفع كل هذه الملفات على مستودع GitHub (في الفرع main).
2. روح على تبويب **Actions** في المستودع.
3. رح تلاقي عملية بناء اسمها "بناء تطبيق APK" تشتغل تلقائياً.
4. استنى لما تخلص (علامة ✓ خضراء) — تاخد حوالي 5-10 دقائق.
5. اضغط على العملية، وانزل تحت لقسم **Artifacts**.
6. نزّل ملف **aswaq-fakahani-apk** — جواه ملف APK جاهز.
7. حوّل الملف لجهاز الطلبات ونزّله (فعّل "تثبيت من مصادر غير معروفة").

## ملاحظات

- الملف من نوع Debug APK — مناسب للاستخدام الشخصي على جهازك.
- لو ما اشتغلت العملية تلقائياً، روح Actions واضغط "Run workflow" يدوياً.
- اللوحة مربوطة بقاعدة بيانات Firebase، فلازم الجهاز يكون متصل بالإنترنت.

## الملفات

- `www/index.html` — لوحة الطلبات (الكود الكامل).
- `capacitor.config.json` — إعدادات التطبيق (الاسم، المعرّف).
- `package.json` — حزم Capacitor.
- `.github/workflows/build-apk.yml` — سكربت البناء التلقائي.
